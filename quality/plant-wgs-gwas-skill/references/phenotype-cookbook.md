# 植物表型处理手册

> 目标：把田间观测值变成可用于 GWAS 的**遗传表型**，并选对变换与协变量。这是本 Skill 相对原书（人类单点表型）最主要的迁移增补。

## 1. 三条硬规则

1. **多环境/多年/区组重复，必须先取 BLUP/BLUE 再 GWAS**。直接用单点观测值会把环境方差当作遗传信号的一部分，稀释功效并制造假阴性。
2. **变换前后都画分布与 Q-Q 图**，确认偏态与离群已处理（原书 PDF p53–54 用 Q-Q 图检查分布）。
3. **协变量只放先于表型、不由基因型决定的变量**；把 PC 与批次同时纳入时检查共线性（原书 PDF p238 用 `--covar`）。

## 2. 表型路由表

| 表型 | 类型 | 常见问题 | 建议变换 | 必带协变量（示例） | 备注 |
| --- | --- | --- | --- | --- | --- |
| 株高 | 连续，近正态 | 多环境、区组、生育期差异 | 一般无需；必要时 log | 播期、密度、区组、生育期 | 适合做阳性对照（已知株高基因） |
| 分支数 / 分蘖数 | 计数，右偏 | 零膨胀、泊松/负二项 | `sqrt(x)` 或 `log(x+1)`；严重偏态用分位数正态变换 | 密度、养分、种植方式 | 零膨胀严重时改用计数型 GLMM |
| 开花时间 | 连续（天数/积温），常右偏或双峰 | 强 G×E、光温敏感 | log / Box-Cox；也可阈值化为早/迟二分类 | 播期、春化、光周期、温度 | 多环境必须报告 G×E；可用已知 FT 类基因做阳性对照 |
| 抗病等级 | 有序分类 | 等级间距不等 | 累积 link 模型；或阈值二分 | 接种批次、菌系、鉴定人 | 二分后用 `--logistic`（书中 p236–237） |
| 存活 / 萌发 | 二分类 | 比例极端 | 不变换，logistic | 处理、批次 | 输出 OR 而非 BETA |
| 产量 / 千粒重 | 连续，遗传力偏低 | 环境方差大 | BLUP 必需 | 区组、密度、水肥 | 低遗传力 → 需更大样本与重复 |
| 代谢物 / 品质 | 连续高维，常偏态 | 多重检验维度再膨胀 | log + 分位数正态 | 取样批次、仪器批次 | 每个代谢物单独 GWAS，阈值更严（mGWAS） |
| 比值 / 指数类（如收获指数） | 连续，比例 | 边界聚集、方差不齐 | logit 或 arcsine sqrt | 同上 | 注意分子分母的相关性 |

## 3. BLUP / BLUE 怎么取

推荐用田间试验的线性混合模型（R `lme4` / `sommer` / `ASReml` / `rrBLUP`）：

```
y_ijk = μ + G_i（基因型，随机或固定） + E_j（环境） + G×E_ij + R_k(E_j)（区组） + e_ijk
```

- 需要**基因型 BLUP** 作为 GWAS 输入时，把基因型设为随机效应；
- 需要 BLUE 时设为固定效应；
- 有空间变异（田间梯度）时加空间协变量或行列随机效应；
- 记录每个表型的 BLUP 可靠性（如 `H²` / repeatability），低可靠性表型应在报告中标注功效受限。

**关键**：BLUP 已经"借用"了群体信息，若后续再用同一批基因型做 K 矩阵，需注意可能引入轻微收缩偏差；常规做法是报告时说明 BLUP 来源，并用原始多环境均值做一次敏感性分析。

## 4. 表型文件格式

`assets/phenotype_template.tsv` 的列约定：

```
FID  IID  <phenotype_columns...>  batch  location  year
```

- `IID` 必须与 VCF 样本名完全一致（PLINK `.fam` 第 2 列）。
- 缺失统一用 `NA`，不要用 `0`、`-9`、空字符串混用（书中 PDF p215 提到 `.fam` 用 −9 表示缺失，PLINK 有专门处理）。
- 每个表型建议单独一个文件（或一个宽表 + `column` 指定列），由 `phenotypes[].column` 明确指定。
- 保留一份"原始观测值"表，不要只留变换后的值。

## 5. 分布检查清单

- [ ] 样本量、缺失数、唯一值数
- [ ] 均值/中位数/SD/偏度/峰度、最小最大值
- [ ] 直方图与 Q-Q 图（正态性）
- [ ] 离群值：生物学合理范围之外的记录逐条核查，不自动删除
- [ ] 按亚群/批次分层看表型分布差异——若某亚群整体偏高，GWAS 极易出结构假阳性
- [ ] 表型与 PC 的相关系数（用于判断结构校正强度）
- [ ] 多环境：各环境间表型相关、G×E 方差占比

## 6. 协变量整理

`assets/sample_sheet_template.tsv` 记录 `batch`、`location`、`year`、`population` 等。构造协变量文件时：

- 分类变量转哑变量（n 类 → n−1 列）；
- 连续协变量标准化（`--covar-variance-standardize`）；
- **不要把"被检验的标记"或"由基因型决定的标签"放进协变量**；
- 把 PC 列（来自 `02_structure.sh` 的 `.eigenvec`）与上述协变量合并成一份 `covariates.tsv`，首两列 FID/IID。

## 7. G×E 与多环境策略

| 策略 | 做法 | 适用 |
| --- | --- | --- |
| 汇总后 GWAS | BLUP 跨环境均值 → 单次 GWAS | 主效稳定、目标为广适性位点 |
| 分环境 GWAS | 每环境单独跑，比较位点一致性 | 寻找环境特异位点 |
| 多变量 / 多性状 | MTAG 或多性状 LMM（第 12 章，PDF p332 起） | 提升功效、估计遗传相关 |
| G×E 交互项 | 标记 × 环境交互检验 | 有明确环境梯度假设时 |

无论哪种，报告中都要写明表型来自哪个环境、是否含 G×E，避免过度外推。

## 8. 常见错误

1. 单点观测值直接 GWAS（最常见）。
2. 把计数型表型当正态连续变量直接用（分支数、分蘖数）。
3. 变换后忘记检查分布，反而放大了离群。
4. 协变量里混入亚群标签，把真实结构信号"校正掉"或制造共线。
5. 缺失编码混乱导致样本被静默丢弃。
6. 不在报告写明表型是 BLUP 还是原始值，别人无法复现。
