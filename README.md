# gwas-candidate-annotation
End-to-end GWAS candidate-gene annotation AI Skill: dual-model lead SNP screening, GFF window gene extraction, CDS/protein translation, multi-database BLASTp, polyploid homolog copy inventory, TE risk flags, and cloning/KASP/hormone-rescue prioritization. Built for polyploid crops such as alfalfa; also works for diploids.
