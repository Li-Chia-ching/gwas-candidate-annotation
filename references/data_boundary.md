# 数据边界与汇报口径（截断 GWAS 交付物）

## 截断数据的典型交付形态

供应商按 P 值阈值截断交付时，到手的是：
- `*_signals.csv`：仅 P<阈值的显著位点（统计量摘要）；
- `*.ann.vcf`：仅显著位点的迷你 VCF（虽含全样本 GT 列，但只覆盖显著位点）；
- **未交付**：全基因组基因型 VCF、全量 P 值/Effect/SE。

实测案例（已脱敏为量级）：原始 callset 约 3,400 万 SNP → 硬过滤后约 360 万（约 11%，MAF≥0.05 + max-missing 0.9 + 二态）→ 到手仅约 1.2 万条 P<1e-5 信号。

## 能做 / 不能做

| 能做 | 不能做 |
|:--|:--|
| 显著信号的注释解读、双模型交叉、窗口候选基因 | 重跑 GWAS、换阈值（Bonferroni/Meff 正式检验） |
| 显著位点间 LD（实测 r²） | 完整区域 LD 区块、LD 衰减距离 |
| Manhattan 图（标注截断） | 可靠的 Q-Q 图与 λgc（P 值在阈值处截断，λ 不可估） |
| 候选基因同源注释与克隆优先级 | 独立 QTL 判定、统计共定位（coloc）、单倍型分析 |

## 汇报口径（组会/论文安全表述）

- ✅ "高置信关联候选位点/候选基因"；
- ❌ 禁止表述为"稳定 QTL""因果基因""已定位功能基因"；
- "某区域无显著信号" ≠ "该区域无变异"——可能未过阈值、被 MAF/missing 过滤、或未进入交付 callset；
- 双模型（MLM+FarmCPU）同位置显著 = 假阳性风险降低，**不等于**独立 QTL。

## 推动完整数据释放的最小需求清单

- P0：全量过滤后 VCF（含全部样本 GT）；
- P0：三模型全量 summary statistics（P/Effect/SE，无截断）；
- P0：最终表型文件、单位、样本 ID 对照表；
- P1：核心区域 BAM/CRAM 或局部比对 QC；
- P1：不同参考版本间的坐标/基因映射表。
