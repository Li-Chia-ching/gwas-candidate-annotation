# Third-party components and licenses

This repository does not vendor third-party executables or fonts.

## Runtime dependencies

- Python 3.11+
- NumPy 2.5.4 (BSD-3-Clause)
- Matplotlib 3.11.2 (BSD-style license)
- PyYAML 6.0.3 (MIT)
- NCBI BLAST+ 2.17.0 (`blastp`, `makeblastdb`); obtain from NCBI and follow the upstream license/terms

## Fonts

Figures request the system Arial font. No Arial font file is distributed with this repository. Users must use a licensed system font or modify the plotting configuration to a licensed alternative.

## Test evidence

Constructed test data under `examples/minimal/` are synthetic and contain no personal, patient, or project-identifying records.
